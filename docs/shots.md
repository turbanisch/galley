# Screenshots and clips for the README

Each `<!-- shot: … -->` comment in `README.md` marks where one goes. Put the files in
`docs/media/` and replace the comment with `![Description](docs/media/name.png)`.

Use your own paper (Fuchs and Turbanisch 2026) and own slides where possible – the published
papers in `test-pdf/` are copyrighted.

## Setup

- Window about 1400 × 900, light mode, sidebar open, Reading Size.
- Stills: ⇧⌘4, then Space, click the window (⌥ while clicking drops the shadow).
- Clips: ⇧⌘5 → Record Selected Portion, 5–10 seconds each, no narration. Convert to GIF
  (e.g. Gifski, free) at about 900 px wide, or drag the .mov into a GitHub comment box to get an
  .mp4 link that plays inline.
